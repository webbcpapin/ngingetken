04 / TENTANG

Inovasi lokal, komitmen bersama.

Ngingetken, dari bahasa Bangka yang berarti mengingatkan, dikembangkan sejak 2018 untuk menguatkan integritas dan kepedulian antarrekan di Bea Cukai Pangkalpinang. Versi 2.0 menambahkan pusat pengetahuan sebagai sarana pencegahan dan pembelajaran.

Website GitHub Pages ini dapat diakses publik, sedangkan akses pengisian dibatasi melalui pengaturan Microsoft Forms organisasi. Website tidak menggantikan WISE atau aplikasi resmi DJBC.
