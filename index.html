Jangan menyebarkan penilaian berdasarkan penampilan. Pisahkan rumor dari fakta dan jaga privasi.

04

02 / LATIHAN KOMPETENSI

Uji pertimbangan Anda melalui 45 situasi kerja.

Modul latihan Situational Judgment Test (SJT) berbentuk Best–Worst: tentukan tindakan paling efektif dan paling tidak efektif pada setiap kasus. Meliputi sembilan kompetensi ASN dan dilengkapi umpan balik berdasarkan kunci draf.

Instrumen belum divalidasi asesor. Hasil hanya untuk pembelajaran, bukan skor integritas atau penilaian kompetensi resmi. Tidak meminta identitas dan tidak menyimpan jawaban secara otomatis.

04 / TENTANG

Inovasi lokal, komitmen bersama.

Ngingetken, dari bahasa Bangka yang berarti mengingatkan, dikembangkan sejak 2018 untuk menguatkan integritas dan kepedulian antarrekan di Bea Cukai Pangkalpinang. Versi 2.0 menambahkan pusat pengetahuan, ruang aksi berisi alat bantu pengingat dan apresiasi, serta latihan SJT edukatif.

Website GitHub Pages ini dapat diakses publik, sedangkan akses pengisian dibatasi melalui pengaturan Microsoft Forms organisasi. Website tidak menggantikan WISE atau aplikasi resmi DJBC.
