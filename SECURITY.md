# SECURITY.md — Pengamanan Ngingetken

Repository publik sebelumnya memuat data pegawai dan respons historis. Penggantian tree branch utama menghapus file tersebut dari versi website terbaru, tetapi TIDAK menghapus commit lama, fork, cache maupun unduhan yang sudah terjadi.

## Perlu segera ditindaklanjuti bersama TIK
1. Konfirmasi salinan data dan respons yang diperlukan sudah disimpan aman di penyimpanan resmi organisasi.
2. Ganti atau cabut password/token yang pernah ditempatkan dalam JavaScript maupun Apps Script.
3. Audit izin Microsoft Forms, Google Sheet/Apps Script lama, serta deployment API.
4. Koordinasikan penghapusan sejarah Git atau migrasi ke repository baru yang bersih, termasuk bantuan GitHub Support bila diperlukan.
5. Jangan menaruh data pribadi, identitas pelapor, respons pegawai, dan dugaan pelanggaran di GitHub Pages.
6. Tetapkan SOP akses, validasi informasi, retensi, dan eskalasi pengaduan sesuai kewenangan.

## Batasan
Fitur formulir Ngingetken hanya berupa tautan Microsoft Forms internal. WISE merupakan jalur pelaporan dugaan pelanggaran. Fitur Saling Ngingetken harus untuk masukan preventif dan tidak memuat tuduhan.

## Status
Belum ada klaim bahwa penghapusan histori Git, pencabutan kredensial, atau pembatasan akses Forms sudah selesai. Langkah tersebut harus dilakukan dan diverifikasi pengelola.
