# Roadmap Pengembangan Setelah v4

## Versi 4.1
- Pertanyaan form benar-benar dinamis dari sheet `form_questions`.
- Fitur edit pegawai dan edit periode dari UI.
- Filter keterlambatan berdasarkan tanggal deadline.

## Versi 4.2
- Reminder otomatis melalui Gmail/Google Workspace.
- Template pesan per unit.
- Export PDF laporan pimpinan.

## Versi 5
- Login Google Workspace atau Microsoft Entra ID.
- Role-based access control.
- Integrasi Microsoft Teams.
- Dashboard tren lintas periode.
- AI summary laporan bulanan.

## Versi Enterprise
- Database PostgreSQL/Supabase.
- Backend Node.js/FastAPI.
- Audit trail lebih kuat.
- Enkripsi data dan manajemen akses formal.
